# 🍽️ Proyecto Recetas - Base de Datos Compartida

Aplicación en Python con interfaz gráfica (Tkinter) que permite gestionar recetas y compararlas según su tiempo de preparación.  
El sistema está conectado a una base de datos PostgreSQL en la nube (Supabase), permitiendo trabajo colaborativo.

---

## 🚀 Características

- Registrar recetas (nombre y tiempo)
- Evitar duplicados
- Mostrar lista ordenada por tiempo
- Comparar recetas respecto a la más rápida
- Interfaz gráfica amigable (Tkinter)
- Base de datos compartida en línea (PostgreSQL)

---

## 🧠 Tecnologías usadas

- Python 3
- Tkinter (interfaz gráfica)
- PostgreSQL (base de datos)
- psycopg2 (conexión a la base de datos)
- python-dotenv (variables de entorno)
- Supabase (hosting de la base de datos)
